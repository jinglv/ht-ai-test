## 一、全局约定

### 1.1 基础约定

| 项目 | 约定 |
| ---- | ---- |
| 接口前缀 | `/api/v1` |
| 传输格式 | `application/json`（文件上传除外，用 `multipart/form-data`） |
| 字符编码 | UTF-8 |
| 鉴权 | `Authorization: Bearer <JWT>`（除登录/验证码/健康检查外所有接口） |
| 时区 | 所有时间字段统一 UTC，前端展示转本地时区；落库用 `timestamptz` |
| 分页参数 | `page`（页码，从 1 开始，默认 1）、`page_size`（每页条数，默认 20，最大 100） |
| 排序参数 | `ordering`（逗号分隔字段名，前缀 `-` 表示降序，如 `-created_at`） |
| 软删除 | 默认查询过滤 `is_deleted=false`；删除接口走 DELETE 即软删除 |
| 权限校验 | 接口级 `require_permission("domain:action")` + 数据权限 `get_data_scope()` 双层过滤 |

### 1.2 统一响应结构

所有接口统一返回如下结构（PRD §6）：

```json
{
  "code": 0,
  "message": "success",
  "data": { }
}
```

| 字段 | 类型 | 说明 |
| ---- | ---- | ---- |
| code | int | 业务码。`0` = 成功；非 `0` = 业务/系统错误 |
| message | string | 提示信息，简体中文 |
| data | object/array/null | 业务数据。列表接口为 `{items, total, page, page_size}` |

**列表分页 data 结构：**

```json
{
  "items": [],
  "total": 0,
  "page": 1,
  "page_size": 20
}
```

### 1.3 业务码定义

| code | HTTP 状态 | 含义 |
| ---- | --------- | ---- |
| 0 | 200 | 成功 |
| 1001 | 400 | 参数校验失败 |
| 1002 | 401 | 未登录或 Token 失效 |
| 1003 | 403 | 无操作权限 |
| 1004 | 404 | 资源不存在 |
| 1005 | 409 | 资源冲突（如编号重复） |
| 1006 | 422 | 业务规则校验失败（如角色被占用禁止删除） |
| 1007 | 429 | 请求过于频繁（限流） |
| 2001 | 400 | 验证码错误或已过期 |
| 2002 | 400 | 用户名或密码错误 |
| 2003 | 403 | 账号已禁用 |
| 3001 | 500 | AI 调用失败（DeepSeek 超时/限流） |
| 3002 | 403 | AI 查询越权（数据权限拦截） |
| 3003 | 400 | nl2sql 生成失败或非只读 SQL |
| 5000 | 500 | 服务器内部错误 |

### 1.4 通用错误响应

```json
{
  "code": 1001,
  "message": "username 不能为空",
  "data": null
}
```

### 1.5 通用请求头

| Header | 是否必填 | 说明 |
| ------ | -------- | ---- |
| `Authorization` | 是（除白名单） | `Bearer <JWT>` |
| `Content-Type` | 是 | `application/json` 或 `multipart/form-data` |
| `X-Request-Id` | 否 | 请求追踪 ID，服务端未传则自动生成并回写响应头 |

## 二、认证模块

> 路由：`backend/src/hetu/modules/auth/router.py`
> 对应 PRD §3.1.2 登录认证、§6 认证接口。

### 2.1 获取登录验证码

`GET /api/v1/auth/captcha`

获取登录页图形验证码，返回 Base64 编码图片与唯一 `captcha_id`。

**请求参数：** 无

**响应 data：**

```json
{
  "captcha_id": "a1b2c3d4e5f6",
  "image": "data:image/png;base64,iVBORw0KGgo...",
  "expires_in": 300
}
```

| 字段 | 类型 | 说明 |
| ---- | ---- | ---- |
| captcha_id | string | 验证码唯一 ID，登录时回传 |
| image | string | Base64 编码图片（含 `data:image/png;base64,` 前缀） |
| expires_in | int | 有效期（秒），默认 300 |

### 2.2 登录

`POST /api/v1/auth/login`

账号密码登录，含验证码校验。返回 JWT。

**请求体：**

```json
{
  "username": "admin",
  "password": "hetu@2026",
  "captcha_id": "a1b2c3d4e5f6",
  "captcha_code": "ABCD",
  "remember": false
}
```

| 字段 | 类型 | 必填 | 说明 |
| ---- | ---- | ---- | ---- |
| username | string | 是 | 用户名 |
| password | string | 是 | 明文密码（HTTPS 传输，后端 bcrypt 校验） |
| captcha_id | string | 是 | 来自 2.1 |
| captcha_code | string | 是 | 用户输入的验证码 |
| remember | boolean | 否 | 记住密码：JWT 有效期延长至 30 天，默认 7 天 |

**响应 data：**

```json
{
  "token": "eyJhbGciOiJIUzI1NiIsInR5cCI6IkpXVCJ9...",
  "token_type": "bearer",
  "expires_in": 604800,
  "user": {
    "id": 1,
    "username": "admin",
    "real_name": "超级管理员",
    "email": "admin@hetu.io",
    "avatar": null,
    "is_super": true,
    "roles": [{"id": 1, "code": "super_admin", "name": "超级管理员"}],
    "permissions": ["*"]
  }
}
```

> 超级管理员 `permissions` 返回 `["*"]` 表示拥有全部权限；普通用户返回具体权限码数组（菜单+操作）。

### 2.3 退出登录

`POST /api/v1/auth/logout`

使当前 JWT 失效（加入黑名单或清前端缓存）。

**请求体：** 无

**响应 data：** `null`

### 2.4 获取当前用户信息

`GET /api/v1/auth/me`

刷新登录后用于回填前端用户区、菜单、权限点。

**响应 data：**

```json
{
  "id": 1,
  "username": "admin",
  "real_name": "超级管理员",
  "email": "admin@hetu.io",
  "phone": "13800000000",
  "avatar": null,
  "is_super": true,
  "is_active": true,
  "last_login_at": "2026-07-27T10:00:00Z",
  "roles": [{"id": 1, "code": "super_admin", "name": "超级管理员", "data_scope": "all"}],
  "permissions": ["*"]
}
```

### 2.5 修改密码

`PUT /api/v1/auth/password`

个人中心修改密码。

**请求体：**

```json
{
  "old_password": "hetu@2026",
  "new_password": "Hetu@2026New",
  "confirm_password": "Hetu@2026New"
}
```

**响应 data：** `null`

### 2.6 修改个人信息

`PUT /api/v1/auth/profile`

```json
{
  "real_name": "李四",
  "email": "lisi@hetu.io",
  "phone": "13900000000",
  "avatar": "/uploads/avatar/1.png"
}
```

**响应 data：** 返回更新后的用户对象（同 2.4 `user` 部分）

## 三、用户管理模块

> 路由：`backend/src/hetu/modules/rbac/router.py`（user 部分）
> 对应 PRD §3.1.2 用户管理。权限：`user:manage`。

### 3.1 用户列表

`GET /api/v1/users`

**Query 参数：**

| 参数 | 类型 | 必填 | 说明 |
| ---- | ---- | ---- | ---- |
| keyword | string | 否 | 模糊搜索 username/real_name/email |
| is_active | boolean | 否 | 按启用状态过滤 |
| role_id | int | 否 | 按角色过滤 |
| page | int | 否 | 默认 1 |
| page_size | int | 否 | 默认 20 |
| ordering | string | 否 | 如 `-created_at` |

**响应 data：**

```json
{
  "items": [
    {
      "id": 2,
      "username": "tester01",
      "real_name": "张三",
      "email": "zhangsan@hetu.io",
      "phone": "13800000001",
      "avatar": null,
      "is_active": true,
      "is_super": false,
      "last_login_at": "2026-07-26T18:30:00Z",
      "roles": [{"id": 3, "code": "tester", "name": "测试工程师"}],
      "created_at": "2026-07-01T09:00:00Z"
    }
  ],
  "total": 25,
  "page": 1,
  "page_size": 20
}
```

### 3.2 用户详情

`GET /api/v1/users/{id}`

**响应 data：** 单个用户对象（同 3.1 items 元素，含 `permissions` 字段）

### 3.3 创建用户

`POST /api/v1/users`

```json
{
  "username": "tester02",
  "password": "Init@2026",
  "real_name": "李四",
  "email": "lisi@hetu.io",
  "phone": "13900000000",
  "is_active": true,
  "role_ids": [3]
}
```

| 字段 | 类型 | 必填 | 说明 |
| ---- | ---- | ---- | ---- |
| username | string | 是 | 唯一 |
| password | string | 是 | 明文，后端 bcrypt 哈希 |
| real_name | string | 是 | |
| email | string | 否 | 唯一 |
| phone | string | 否 | |
| is_active | boolean | 否 | 默认 true |
| role_ids | int[] | 否 | 角色 ID 列表 |

**响应 data：** 创建后的用户对象（含 `id`）

### 3.4 更新用户

`PUT /api/v1/users/{id}`

```json
{
  "real_name": "李四-改",
  "email": "lisi2@hetu.io",
  "phone": "13900000001",
  "is_active": true,
  "role_ids": [3, 4]
}
```

> `username` 不可修改；`password` 不在此接口修改。

**响应 data：** 更新后的用户对象

### 3.5 删除用户

`DELETE /api/v1/users/{id}`

> 软删除用户（`is_active=false`），不实际删除数据。超级管理员账号不可删除。

**响应 data：** `null`

### 3.6 启用/禁用用户

`PATCH /api/v1/users/{id}/status`

```json
{ "is_active": false }
```

> 禁用后下次请求 JWT 校验失败（PRD §3.1.5 规则 3）。

**响应 data：** 更新后的用户对象

### 3.7 重置密码

`POST /api/v1/users/{id}/reset-password`

```json
{ "new_password": "NewInit@2026" }
```

> 管理员重置他人密码，原密码失效。

**响应 data：** `null`

### 3.8 分配角色

`PUT /api/v1/users/{id}/roles`

```json
{ "role_ids": [2, 3] }
```

> 全量覆盖该用户的角色（移除未传的）。

**响应 data：** 更新后的用户对象（含 roles）

## 四、角色管理模块

> 路由：`backend/src/hetu/modules/rbac/router.py`（role 部分）
> 对应 PRD §3.1.2 角色管理。权限：`role:manage`。

### 4.1 角色列表

`GET /api/v1/roles`

**Query 参数：**

| 参数 | 类型 | 必填 | 说明 |
| ---- | ---- | ---- | ---- |
| keyword | string | 否 | 模糊搜索 name/code |
| is_builtin | boolean | 否 | 按内置角色过滤 |
| page / page_size | int | 否 | 分页 |

**响应 data：**

```json
{
  "items": [
    {
      "id": 1,
      "name": "超级管理员",
      "code": "super_admin",
      "description": "拥有全部权限，数据权限固定为 ALL",
      "data_scope": "all",
      "is_builtin": true,
      "user_count": 1,
      "created_at": "2026-07-01T00:00:00Z"
    }
  ],
  "total": 4,
  "page": 1,
  "page_size": 20
}
```

### 4.2 角色详情

`GET /api/v1/roles/{id}`

**响应 data：** 含 `permissions` 数组（角色已绑定的权限点，含 id/code/name/type）

### 4.3 创建角色

`POST /api/v1/roles`

```json
{
  "name": "测试组长",
  "code": "test_lead",
  "description": "测试团队负责人",
  "data_scope": "project",
  "permission_ids": [1, 5, 6, 7, 8]
}
```

| 字段 | 类型 | 必填 | 说明 |
| ---- | ---- | ---- | ---- |
| name | string | 是 | 唯一 |
| code | string | 是 | 唯一 |
| description | string | 否 | |
| data_scope | string | 否 | `self`/`project`/`all`，默认 `self` |
| permission_ids | int[] | 否 | 权限点 ID 列表 |

**响应 data：** 创建后的角色对象

### 4.4 更新角色

`PUT /api/v1/roles/{id}`

```json
{
  "name": "测试组长-改",
  "description": "更新描述",
  "data_scope": "all"
}
```

> `code` 不可修改；内置角色不可修改 `data_scope`（超级管理员固定 ALL）。

**响应 data：** 更新后的角色对象

### 4.5 删除角色

`DELETE /api/v1/roles/{id}`

> PRD §3.1.5 规则 2：删除前校验是否有用户占用，占用时返回 `1006` 业务错误。内置角色（`is_builtin=true`）不可删除。

**响应 data：** `null`

**冲突响应示例：**

```json
{ "code": 1006, "message": "角色【测试经理】仍被 5 个用户使用，无法删除", "data": null }
```

### 4.6 为角色绑定权限

`PUT /api/v1/roles/{id}/permissions`

```json
{ "permission_ids": [1, 5, 6, 7, 8, 12] }
```

> 全量覆盖。内置超级管理员角色的权限不可修改。

**响应 data：** 更新后的角色对象（含 permissions）

## 五、权限管理模块

> 路由：`backend/src/hetu/modules/rbac/router.py`（permission 部分）
> 对应 PRD §3.1.2 权限管理。权限：`permission:manage`（除树查询外）。

### 5.1 权限树

`GET /api/v1/permissions/tree`

获取树形权限点（菜单/操作/数据三类）。

**Query 参数：**

| 参数 | 类型 | 必填 | 说明 |
| ---- | ---- | ---- | ---- |
| type | string | 否 | 过滤权限类型 `menu`/`action`/`data` |

**响应 data：**

```json
[
  {
    "id": 1,
    "name": "首页工作台",
    "code": "dashboard:view",
    "type": "menu",
    "path": "/dashboard",
    "icon": "home",
    "sort": 1,
    "children": []
  },
  {
    "id": 5,
    "name": "用例管理",
    "code": "testcase:view",
    "type": "menu",
    "path": "/testcases",
    "icon": "file-text",
    "sort": 3,
    "children": [
      { "id": 6, "name": "创建用例", "code": "testcase:create", "type": "action", "sort": 1, "children": [] },
      { "id": 7, "name": "AI 生成用例", "code": "testcase:ai_generate", "type": "action", "sort": 2, "children": [] }
    ]
  }
]
```

### 5.2 权限点列表（扁平）

`GET /api/v1/permissions`

**Query 参数：** `type`（过滤类型）、`keyword`、`page`/`page_size`

**响应 data：** 同 2.1 列表结构，items 元素为单个权限点对象。

### 5.3 创建权限点

`POST /api/v1/permissions`

```json
{
  "name": "导出用例",
  "code": "testcase:export",
  "type": "action",
  "parent_id": 5,
  "sort": 3
}
```

**响应 data：** 创建后的权限点对象

### 5.4 更新权限点

`PUT /api/v1/permissions/{id}`

```json
{ "name": "导出用例-改", "sort": 4 }
```

> `code` 不可修改（防止权限码漂移）。

**响应 data：** 更新后的权限点对象

### 5.5 删除权限点

`DELETE /api/v1/permissions/{id}`

> 若有子节点或被角色引用，返回 `1006` 业务错误。

**响应 data：** `null`

## 七、项目模块管理

> 路由：`backend/src/hetu/modules/project/router.py`（module 部分）
> 对应 PRD §3.2.2 模块划分。权限：`project:create`。

### 7.1 模块树

`GET /api/v1/projects/{project_id}/modules`

获取项目下的树形模块。

**响应 data：**

```json
[
  {
    "id": 1,
    "name": "登录认证",
    "sort": 1,
    "children": [
      { "id": 2, "name": "账号密码登录", "sort": 1, "children": [] },
      { "id": 3, "name": "验证码", "sort": 2, "children": [] }
    ]
  }
]
```

### 7.2 创建模块

`POST /api/v1/projects/{project_id}/modules`

```json
{
  "name": "登录认证",
  "parent_id": null,
  "sort": 1
}
```

| 字段 | 类型 | 必填 | 说明 |
| ---- | ---- | ---- | ---- |
| name | string | 是 | |
| parent_id | int | 否 | 父模块 ID，null 表示顶级 |
| sort | int | 否 | 默认 0 |

**响应 data：** 创建后的模块对象

### 7.3 更新模块

`PUT /api/v1/projects/{project_id}/modules/{id}`

```json
{ "name": "登录认证-改", "sort": 2 }
```

**响应 data：** 更新后的模块对象

### 7.4 删除模块

`DELETE /api/v1/projects/{project_id}/modules/{id}`

**响应 data：** `null`

### 7.5 拖拽排序模块

`PUT /api/v1/projects/{project_id}/modules/sort`

```json
{
  "updates": [
    { "id": 1, "sort": 1, "parent_id": null },
    { "id": 2, "sort": 1, "parent_id": 1 },
    { "id": 3, "sort": 2, "parent_id": 1 }
  ]
}
```

**响应 data：** `null`

| 字段 | 类型 | 必填 | 说明 |
| ---- | ---- | ---- | ---- |
| conversation_id | int | 否 | 为空则新建会话 |
| message | string | 是 | 用户提问（自然语言） |
| context.project_id | int | 否 | 当前上下文项目，用于数据权限过滤 |

**响应：** `text/event-stream`（SSE）

每条事件以 `event:` / `data:` 组成，事件类型如下：

| event | data | 说明 |
| ----- | ---- | ---- |
| `conversation` | `{"conversation_id": 1, "title": "HT-CORE 用例通过率分析"}` | 新建/复用会话信息（首事件） |
| `delta` | `{"content": "正在"}` | 文本增量（打字机效果） |
| `table` | `{"columns": [...], "rows": [...]}` | 数据表格（nl2sql 结果集） |
| `chart` | `{"chart_config": {...}}` | 图表配置（visualization 技能输出） |
| `tool` | `{"name": "nl2sql", "input": {...}, "output": {...}}` | 工具调用过程（可选，用于展示 agent 思考链） |
| `done` | `{"message_id": 42, "token_input": 320, "token_output": 180, "latency_ms": 2800}` | 结束事件，含计量 |
| `error` | `{"code": 3002, "message": "查询越权：项目数据权限不足"}` | 错误事件 |

**SSE 流示例：**

```
event: conversation
data: {"conversation_id": 1, "title": "HT-CORE 用例通过率分析"}

event: tool
data: {"name": "nl2sql", "input": {"question": "按模块统计用例通过率"}, "output": {"sql": "SELECT ..."}}

event: table
data: {"columns": ["模块", "用例总数", "通过数", "通过率"], "rows": [["登录认证", 45, 42, 0.93], ...]}

event: chart
data: {"chart_config": {"chart_type": "bar", "x_field": "module", "y_field": "pass_rate", "series": [...]}}

event: delta
data: {"content": "根据"}

event: delta
data: {"content": "查询结果"}

event: delta
data: {"content": "，HT-CORE 项目"}

event: done
data: {"message_id": 42, "token_input": 320, "token_output": 180, "latency_ms": 2800}
```

> 后端 hetu_agent 识别意图后路由到对应技能：需求分析类 -> `requirement_analysis`；用例生成类 -> `testcase_generation`；数据查询类 -> `nl2sql`（叠加数据权限过滤）；可视化类 -> `visualization`。
