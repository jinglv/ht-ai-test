# 河图智弈 · 登录页面设计方案
## 一、基础沿用规范
### 1. 标准色值（全局统一）
| 用途                          | 色值    | 色号             |
| ----------------------------- | ------- | ---------------- |
| 主科技蓝                      | #2A76C9 | RGB(42,118,201)  |
| 页面底色（雅白）              | #F8FAFD | RGB(248,250,253) |
| 国风鎏金（装饰/LOGO描边）     | #D4B86A | RGB(212,184,106) |
| 深灰正文/标题（黛青）         | #23344D | RGB(35,52,77)    |
| 浅分割线/输入框边框（浅烟青） | #D7E2F0 | RGB(215,226,240) |
| 占位文字/置灰文本             | #8A99B0 | RGB(138,153,176) |
| 成功色                        | #36B37E | -                |
| 错误提示红                    | #E54C4C | -                |

### 2. 字体规范
- 品牌名称/大标题：**思源宋体 粗体**
- 表单文字、按钮、提示文案：**思源黑体 常规/中等**
- 全局字号：正文14px，标题20–28px，辅助文字12px

### 3. 通用样式
- 统一圆角：表单/按钮 `8px`，登录卡片 `12px`
- 装饰元素：极简河图点阵、细线条云纹（低透明度底纹，不喧宾夺主）
- 风格基调：**明亮通透、极简国风+现代科技**，无复杂雕花

## 二、整体页面布局（全屏居中版式）
页面采用**左右分区经典登录布局**（主流企业后台样式），适配电脑端，结构分为：
> 左侧品牌展示区（56%）+ 右侧登录表单区（44%）
> 左侧：沉浸式深色科技主题；右侧：浅色玻璃拟态表单区，全屏铺满。

> 说明：本方案为**定稿高端版**，已在 `.stitch/designs/login.html` 落地实现，相较早期草案强化了品牌区氛围与登录卡片质感。

### （一）左侧：品牌展示区（占页面宽度 56%）
1. **背景与氛围**
   多层径向渐变深海蓝调（`#07192B → #0C2E48 → #123C58`），叠加：
   - 顶部一道鎏金/科技蓝光带
   - 精细透视网格 + 河图点阵（边缘遮罩柔化）
   - 3 颗极光氛围球缓慢漂移呼吸
   - 3 条科技流线自上而下流动（模拟算力）
   - 底部山水流线纹理
2. **核心元素从上至下（居中纵向排版）**
   - **核心 LOGO**：品牌位图 `logo.png`
     结构：外层 **旋转鎏金光环**（conic-gradient 金蓝渐变，约 9s 一圈缓慢旋转 + 模糊光晕）+ 内层 124px 白色圆盘（承载 logo，上下浮动呼吸动效）。
   - **品牌主标题**：**河图智弈**
     字体：思源宋体 Black，字号约 46px，白色，字间距 0.18em。
   - **钻石分隔**：标题下方一枚鎏金菱形 + 左右渐隐细线。
   - **副标题**：AI 智能体驱动 · 企业级自动化测试平台
     采用**鎏金渐变文字**，字间距 0.24em，居中。
   - **品牌标语**：循河图数理 · 以智弈控测（半透白，字间距 0.18em）。
   - **特性亮点卡片区**（3 张玻璃拟态卡片，纵向排列）：
     | 图标 | 标题 | 描述 |
     | ---- | ---- | ---- |
     | smart_toy | AI 智能体调度 | 多智能体协同，自动编排测试任务 |
     | bolt | 用例智能生成 | 依据需求文档，秒级产出测试用例 |
     | insights | 数据洞察分析 | 通过率、缺陷分布，一键可视化 |
     卡片样式：半透白磨砂玻璃 + 1px 白色描边 + 柔和投影；hover 上浮 + 鎏金描边；左侧渐变科技蓝方形图标。
   - **底部页脚**：© 2026 河图智弈 · AI 智能体测试管理平台（半透白小字，居中，距底部约 32px）。

### （二）右侧：登录表单区（占页面宽度 44%）
1. **区域背景**
   浅色渐变（`#FAFCFF → #EAF1F9`）+ 角落鎏金/青蓝微光 + 河图点阵底纹（遮罩柔化）。
2. **容器（玻璃拟态浮起卡片）**
   最大宽度 **440px**，右侧区域水平垂直居中；
   底色半透白 (`rgba(255,255,255,0.82)`) + 背景模糊 blur(16px)，圆角 `16px`（2xl）；
   分层柔和大投影 + 顶部一道金色高光装饰线；
   内边距约 44–48px。

2. **卡片内布局（从上至下）**
#### 1）表单小标题
文字：**系统登录**
字号 26px，思源宋体粗体，颜色 `#23344D`；
左侧加**4px 宽鎏金渐变竖条**（国风标识）；标题下配副标题「欢迎回来，请登录您的测试平台账号」（12–13px 置灰），再下方一道鎏金渐隐分割线。

#### 2）表单主体（账号 + 密码 + 验证码）
统一输入框样式：
- 高度：48px，圆角 11px，边框默认 `#D7E2F0`，半透白底
- 内边距：左右 44px（含图标位），字体 14px
- 聚焦状态：边框变主色 `#2A76C9` + 4px 柔和青蓝光晕，左侧图标同步变蓝，0.22s 平滑过渡
- 错误状态：边框变红 `#E54C4C`，下方显示 12px 错误提示文字

- 输入项1：用户名/账号
  占位符：请输入登录账号（左侧 person 图标）
- 输入项2：登录密码
  占位符：请输入登录密码，右侧自带「显示/隐藏密码」眼睛图标（线性简约）
- 输入项3：验证码（企业后台标配）
  左侧输入框（verified_user 图标）+ 右侧渐变底验证码框（斜体高亮字，点击刷新）

#### 3）辅助行（记住登录状态 + 忘记密码）
账号密码下方单行布局：
- 左侧：复选框 + 文字「记住登录状态」，文字 13px，`#8A99B0`
- 右侧：文字「忘记密码？」，颜色主蓝 `#2A76C9`，hover 加深

#### 4）登录主按钮
- 尺寸：宽度 100%，高度 52px，圆角 12px
- 常态：科技青蓝渐变底 (`#2A76C9 → #3E8AD8 → #2A76C9`)，白色加粗文字「登 录」，字间距加宽
- Hover：整体上浮 2px + 投影加深 + **一道白色光泽自左向右扫过**
- 按下：轻微回弹缩放
- 禁用状态：底色置灰，文字置灰，不可点击

#### 5）底部补充文案
按钮下方约 40px 位置：
文字：© 2026 河图智弈 测试管理平台 · 版权所有
字号 12px，颜色 `#8A99B0`，居中对齐。

## 三、细节样式 & 国风+科技融合设计
### 1. 专属装饰细节（贯穿页面）
1. **分割线条**
   表单标题与输入框之间，使用**1px细鎏金线条**做分割，弱化厚重感，强化国风属性。
2. **图标体系**
   账号、密码、眼睛图标均使用**线性极简图标**，线条粗细统一，配色跟随文本色，拒绝卡通风格。
3. **动效设计（轻量，企业风不花哨）**
   - 页面加载：品牌区与登录卡片元素**错位淡入上移**（fade-up，逐元素延迟 0.05–0.65s）
   - LOGO：外层鎏金光环缓慢旋转（约 9s/圈）+ 内层圆盘上下浮动呼吸
   - 极光氛围球缓慢漂移、科技流线自上而下流动
   - 输入框聚焦：边框平滑变色 + 青蓝光晕（0.22s）
   - 登录按钮 hover：上浮 + 白色光泽扫过
   - 表单提交中：按钮加载状态（文字变为「登录中...」+ 简约加载图标）

### 2. 多场景适配版本
#### 版本1：移动端适配（单列布局）
窄屏（`< md`）自动隐藏左侧品牌区，改为：
- 顶部：mini 圆形 LOGO（白底鎏金描边）居中
- 下方：登录表单卡片全屏适配宽度，取消左右分区。

#### 版本2：深色/暗黑模式（LOGO 反白版）
若切换暗黑模式：LOGO 采用透明底/反白版本；表单区底色改深，文字整体反白。

#### 版本3：极简纯净版（用于内网/纯办公系统）
移除旋转光环、极光球与点阵底纹，仅保留基础配色 + 鎏金装饰线，风格更严肃正式。

## 四、交互规则（前端落地参考）
1. 账号、密码为空时点击登录，即时弹窗/行内提示「请输入账号/密码」；
2. 账号密码错误，输入框标红，下方提示「账号或密码不正确」；
3. 登录成功后，淡入动画跳转至系统首页（顶部导航+左侧菜单+Tab栏后台主页）；
4. 「忘记密码」点击弹出独立弹窗，沿用页面配色与圆角规范。

## 五、快速落地总结
1. 核心识别：**品牌圆形 LOGO（旋转鎏金光环）** 为视觉核心，左侧沉浸式深色品牌区 + 右侧玻璃拟态登录卡片；国风元素以「鎏金线条 + 短竖标 + 低透明度点阵」克制点缀；
2. 适用场景：企业级 AI 测试平台内网登录页、公网入口页、大屏系统登录；
3. 核心视觉记忆点：深海蓝品牌区 + 科技蓝主视觉 + 鎏金国风细装饰 + 错位入场动效，大气、专业、辨识度强；
4. 落地文件：`.stitch/designs/login.html`（已实现，可直接本地打开预览）。
