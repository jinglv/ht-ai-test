## 前言

本文档为**河图智弈·企业级AI智能体测试平台**全套官方视觉设计规范，适配技术栈：FastAPI + LangChain + DeepAgents Skill智能体服务。整体风格定位：**明亮极简科技风 + 轻量化新中式**，拒绝厚重古风、拒绝花哨UI，主打企业级专业、干净、高级、有品牌辨识度。

核心品牌释义：**河图为上古算法数理图腾，弈为智能体调度、任务博弈、自动化执行**，以古典数理逻辑承载现代AI测试算力。

## 一、品牌视觉核心定位

### 1.1 设计关键词

明亮通透、数理秩序、智能博弈、轻奢国风、硬核科技、企业极简

### 1.2 风格禁忌

- 禁止厚重古风雕花、水墨、复古暗色调
- 禁止卡通、渐变浮夸、高饱和配色
- 禁止杂乱装饰，所有国风元素**仅做点缀、不抢功能主体**

> **渐变口径澄清**：顶栏/侧栏/表头/登录品牌区的「深海蓝纵向或斜向渐变」、主按钮与图表柱体的「青蓝渐变」属于**克制科技渐变**，是允许且鼓励的层次表达；上文「渐变浮夸」特指高饱和彩虹渐变、糖果色渐变、紫粉霓虹等浮夸效果，二者不冲突。

- 主按钮：科技青蓝渐变底 `#2A76C9 → #3D88E0`（135°）、白字、8px 圆角、柔和投影 `0 3px 10px rgba(42,118,201,0.25)`；hover 上浮 1px + 投影加深；内含图标时图标用鎏金 #D4B86A 点缀
- 次按钮：白底、1px 浅烟青边框、科技青蓝字；hover 填入极浅青蓝底
- 文字按钮：科技青蓝文字、无背景边框；hover 下划线
- 危险按钮：危险红 #E54C4C 实底白字，用于删除等破坏性操作

### 7.2 表格样式

- 表头：深海蓝渐变底 `#0E3A52 → #1A4966` + 白色文字 + 底部 2px 鎏金下沿
- 表格行：白底 + 浅烟青 (#F0F4FA) 分行分割线
- 行 hover：极浅科技青蓝高亮（rgba(42,118,201,0.035)）
- 操作列：文字按钮（青蓝「编辑/查看/成员/详情」、危险红「删除」）
- 底部分页栏：sticky 白底 + 顶部 1px 分割线 + 上方柔和投影；左侧「共 N 条记录，当前显示第 X–Y 条」、右侧页码按钮（34×34，选中态青蓝实底白字）

### 7.3 弹窗/表单

- 弹窗12px圆角、白底、浅边框、柔和投影
- 弹窗标题顶部细鎏金装饰横线
- 输入框聚焦变色、错误标红

### 7.4 图表/数据大屏

- 主配色：科技青蓝 (#2A76C9) + 鎏金 (#D4B86A) 点缀，辅以功能状态色（成功绿/警告橙/危险红）
- 图表卡：雅白底 + 1px 浅烟青边框、8px 圆角、左侧 3px 鎏金标题竖线
- 支持柱状图、环形图（conic-gradient 实现饼/环）、指标卡、数据表格
- 线条干净、数据层级清晰；柱状图用青蓝渐变 `#2A76C9→#3D88E0`，重点柱用鎏金渐变 `#D4B86A→#E8C87A` 突出

### 7.5 业务组件规范（全站通用，与原型对齐）

- **搜索框**：白底 + 1px 浅烟青边框 + 8px 圆角，左侧 search 线性图标（#8A99B0）；focus-within 边框变科技青蓝
- **筛选下拉**：复用次按钮样式（白底浅烟青边框 + 青蓝字），与搜索框同行排列
- **状态标签 Tag**：胶囊形（999px 圆角），渐变底 + 1px 同色系边框 + 同色系深色文字；success/warning/plain/danger 四态，对应成功绿/警告橙/置灰/危险红
- **进度条**：6px 高、3px 圆角、灰底 (#E8EDF5)；填充条按通过率区间自动上色——高（≥90%）成功绿渐变、中青蓝渐变、低（<80%）警告橙渐变，右侧显示百分比
- **统计卡（首页）**：白底 12px 圆角 + 浅边框 + 轻投影；左侧 48×48 圆角图标块（青蓝/绿/鎏金/橙四色渐变区分指标），右侧大号数值（26px 粗体）+ 辅助标签；hover 上浮 2px

- **快捷入口**：4 列网格卡片，每项为圆形浅青蓝图标 + 标题 + 描述；hover 浅青蓝底 + 上浮
- **面包屑**：顶栏内，鎏金渐变竖分隔线 + 当前页高亮白色加粗；多级时以 chevron_right 连接
- **会话列表（AI 对话）**：260px 左栏，每项含会话标题 + 相对时间；选中态左侧 3px 鎏金竖线 + 左向右青蓝渐变底
